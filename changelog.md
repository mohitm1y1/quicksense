# QuickSense 1.0.0

- First stable release of QuickSense.
- Fixed QuickSense failing to load in NVDA after adding PDF support.
- Added a QuickSense command layer. Press NVDA+Shift+Q, then T to translate or Ctrl+S to open settings.
- Added AI text summarization through Groq. Press S in the command layer, enter text, and select OK.
- Added Document Assistant. Press D in the command layer to work with TXT, DOCX, and PDF files: ask questions, summarize content, or convert locally between those formats.
- Added EPUB support to Document Assistant for reading and conversion.
- Fixed the QuickSense NVDA Settings panel layout and category placement.
- Kept only source and target language choices in the QuickSense category.
